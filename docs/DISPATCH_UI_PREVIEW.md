# 派单位置与候选界面

## 使用方式

客服在原案件详情的派单区操作：独立核实事故服务区县 → 搜索并确认车辆当前停放地址 → 查询推荐网点 → 核对本次路线用量并明确计算 → 单选网点 → 点击原派单按钮。地址、候选、服务信息分开；预算和技术诊断默认收进“服务状态与高级信息”。不自动派单，不改权限或资格规则。

当前没有高德JS底图。正式页面的顶部是明确标注的示意状态，不能直接用网格创建真实位置；仍使用原Web服务地址搜索和服务端候选确认。真实地图选点需要后续核实JS API配置、安全代理及调用授权，不使用Web服务Key加载浏览器地图，不将其放入前端。

## 不调用接口的开发预览

在管理端Vite开发服务器打开 `/dispatch-preview.html`。该入口未纳入生产构建，也不是新的业务路由或权限入口。它复用正式页面的地图展示、候选单选和位置/查询控制组件，用强制注入的本地Axios adapter处理所有模拟操作，未知操作直接拒绝，没有真实网络回退。

1. 选择合成预览中的广州市、天河区。
2. 填写合成地址并搜索，或点击网格选点；方向键移动、回车也可操作。
3. 确认模拟停车位置。
4. 查询候选并确认模拟计算。
5. 单选网点；也可点击示意图中的网点标记，列表与标记同步。
6. 点击“确认模拟派单”，只显示本地演示结果，不创建正式派单、案件、审计或通知。

预览中的1.80/4.20/7.60 km是固定合成排序数值，不能作为真实道路结果或网点经营证据。预览显示的用量也是独立合成计数，不关联网站真实授权台账。可切换无候选和模拟失败，检查提示及输入保留。

## 安全与状态边界

- 修改停车地址清除旧确认、旧结果及网点选择；查询范围变化仅清除候选选择，不误标停车地址未保存。
- 迟到的确认/路线响应不能恢复已改变的位置和候选。
- 推荐过期或状态不可用时不能选作当前推荐；正式派单仍经原后端重验。
- 搜索、计算均为明确操作；拖动/鼠标悬停/页面初始化不自动计算真实路线。
- 不会把模拟令牌、网格或合成网点传给真实业务服务。无真实底图时不会宣称真实高德定位。
