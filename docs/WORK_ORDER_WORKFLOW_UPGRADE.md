# 工单流程优化实施与验收

依据 2026-11-12 用户确认的规则及模拟图。分阶段验证，每阶段结束记录到 PROGRESS。

| 阶段 | 交付与验收 |
| --- | --- |
| 1. 已有改派入口 | 管理端右上角改为“工单管理”。当前网点旁提供管理员已有的到店后改派操作，抽屉展示原网点、目标网点、原因、交接信息，直接确认。验证权限、未开修条件及既有派单行为未变。 |
| 2. 客服转交与业绩 | 当前负责人或管理员选择启用的客服，记录交接说明并通知接手人。转交后原客服只读，旧页面与直接 API 均不能继续办理。工单完成时保存当时负责客服；撤出完成后不统计，再次完成按新快照计一次。验证待办、各写入口及统计范围。 |
| 3. 回撤与换网点 | 服务端按可撤回的业务动作计算目标步骤、依赖失效及材料范围；前端显示服务端预览，按工单版本确认。验证旧网点不可继续提交，前序材料完整，受影响材料及其衍生内容永久删除，且维修限制不可绕过。 |
| 4. 删除申请 | 未完成工单可申请；等待审批期间冻结各角色写操作，撤销或驳回后恢复。管理员核对范围、流水及工单编号后批准永久删除。验证工单及其材料、资金、通知、历史、申请审批信息均不残留。 |

## 流程边界

- 维修前逐步回撤，前序材料保留，受影响材料永久删除。记录撤回人、时间、原因和步骤，不保留已删除附件的可恢复副本。
- 已进入维修仅在明确确认尚未实际施工时，可纠正误点的核损确认：退回核损，核对后重新确认；不得继续退至报价或派单，不恢复换网点权限。
- 已完工最早退至“已完工、待收车”。完工事实与完工照保留；收车和资金可纠错。资金回撤使用作废或冲销记录保留纠错过程，正确流水保留。
- 仅维修开始前可更换网点，必须重新记录车辆交接信息。新网点重新接单，原网点的到店、报价及其依赖退出流程，受影响材料按预览永久删除。
- 整单删除会删除所有关联信息，包括流水、撤回记录和审批记录；批准前明确显示流水及其金额。该例外只适用于获批整单删除，不改变正常办理的留痕规则。

## 交互验收

- 转交入口在负责人旁；改派在当前网点旁；撤回在当前任务栏；删除申请在“工单管理”。
- 确认界面列出退回目标、永久删除内容、保留内容及必要原因；去除“我已知晓”“我已核对”等确认复选框，明确动作的红色按钮即为核对确认。原因、交接信息、未实际施工事实及永久删除时输入完整编号等业务校验仍需满足。
- 警示使用红色和明确文字，弹窗短暂淡入并尊重减少动效偏好。确认提交期间避免重复；状态变化时刷新并重新核对；仅实际完成后显示成功。
- 实现删除前，核对数据库关联、对象存储原件与衍生文件、后台任务、缓存及备份副本的处理方式。不得把列表隐藏、数据库软删或待清理状态显示为永久删除成功。
