# 价格库导入说明

只有管理员可以上传、预览、确认导入和查询批次/错误。客服只能查询基础资料、价格候选和历史。接口使用既有 JWT 和统一响应，入口为 /api/v1/pricing/imports；Swagger 提供完整契约。管理端“价格数据库 → Excel / CSV 导入”可下载模板并完成全部步骤。

## 字段模板

UTF-8 CSV（可带 BOM）或单工作表 .xlsx；第一行为以下字段，名称与顺序必须一致。CSV 支持引号、逗号和换行转义；XLSX 日期必须为 yyyy-MM-dd 文本，金额推荐文本，公式不被接受。空白行忽略。

| 顺序 | 字段 | 必填 | 规则 |
| --- | --- | --- | --- |
| 1 | brandCode | 是 | 已有品牌编码 |
| 2 | modelCode | 是 | 该品牌下已有车型编码 |
| 3 | internalCode | 是 | 全局唯一的已有标准配件内部编号，且已配置该车型适配 |
| 4 | partName | 否 | 若填写，必须与标准名称一致；不修改名称 |
| 5 | alias | 否 | 若填写，必须是此配件已有别名；不新增或覆盖别名 |
| 6 | priceType | 是 | 下表四个固定枚举之一 |
| 7 | scope | 是 | NATIONAL / REGION / SHOP |
| 8 | regionCode | 条件 | REGION 必须填写已有区域编码；其他范围必须空 |
| 9 | shopCode | 条件 | SHOP 必须填写已有网点编码；其他范围必须空 |
| 10 | amount | 是 | 正数 CNY，最多 16 位整数、2 位小数；不接受零、负数、科学计数或舍入 |
| 11 | sourceCode | 是 | 已有且启用的来源编码；默认字典为 MANUAL、CSV、EXCEL、HISTORICAL_CASE |
| 12 | effectiveFrom | 是 | 合法 yyyy-MM-dd 中国自然日，年份 0001–9999 |
| 13 | effectiveTo | 否 | 合法自然日，须不早于开始日；空表示持续有效 |

| priceType | 含义 |
| --- | --- |
| REPAIR_SHOP_RAW_REFERENCE | 网点原始参考价 |
| PLATFORM_EXTERNAL_REFERENCE | 平台对外参考价 |
| INSURER_HISTORICAL_ASSESSED | 历史保险核损参考价 |
| REPAIR_SHOP_SETTLEMENT_REFERENCE | 网点结算参考价 |

不自动创建品牌、车型、配件、别名、适配关系或组织。批次 source 表示上传格式 CSV/EXCEL，每条价格 sourceCode 是独立数据来源；来源信息在版本上保存快照。HISTORICAL_CASE 仅为参考数据来源类别，本阶段不提供案件导入流程。

## 预览、确认与错误报告

1. GET /template 下载 CSV 字段模板；配置基础资料后填写实际参考数据。
2. POST /previews 上传 multipart 的 file 字段。解析并校验后返回预览 ID、总行数、有效/错误/重复行数和有效期；正式价格表零写入。
3. GET /previews/{id} 分页查看行号、字段、原始上下文、错误及计划动作；GET /previews/{id}/summary 读取概览。预览仅创建者可访问，30 分钟内有效。
4. 检查后 POST /previews/{id}/confirm，JSON 中 confirmed 必须为 true。确认时重新校验主数据、最新版本与并发冲突，不能信任过期预览。
5. GET /batches、/batches/{id}、/batches/{id}/errors 查看结果；管理端可下载当前错误页 JSON，分页读取可获取完整报告。列表单页最多 100，默认 20，稳定排序。

确认只产生 SUCCESS 或 FAILED 批次：任意错误整批正式价格零写入；failureCount 为整批被拒绝行数，错误报告区分实际错误行及因整批失败未落库的有效行。错误包含行号、字段、原因与必要原始上下文，原始值截断到 256 字符。格式无法解析、模板不匹配或超限时直接返回统一 400/413，无法构造有效行的文件不产生预览或正式批次。

同一预览重复确认返回原批次，不重复导入。预览过期确认返回 410，需重新上传。文件最多 10 MiB、20,000 数据行、单元格 256 字符；超过限制请拆批。CSV 逐行、XLSX SAX 解析并限制解压大小，不保存文件或接入对象存储，只保留 SHA-256、预览字段、批次及错误。

## 版本与重复规则

逻辑维度为“内部配件编号解析出的标准配件 + 车型 + 价格类型 + 适用范围及区域/网点”。文件内同维度、同开始日的行全部标记重复，不静默去重。同维度多行按开始日升序校验，原始行号保留；可以在一次确认中追加多个版本。

开始日必须严格晚于数据库最新版本开始日。已有有限截止日时，新开始日必须晚于其截止日，首尾包含的同一天也属于重叠。无期限旧版本随新版本在同一事务截止于新开始日前一天，记录审计与前后版本链接；金额、来源、创建信息始终保留。新版本自身的截止日不能早于开始日。数据库排他约束和保护触发器再次执行这些规则。

示例：旧版本从 2026-01-01 持续有效，追加 2026-02-01 的新版本后，旧版本截止到 2026-01-31；若旧版本原截止于 2026-02-01，则同日新版本被拒绝。导入其他行失败时，此截止修改与全部新增版本一起回滚，失败批次和错误另行保留。

全国、区域、网点候选可以并存；正式价格适用优先级尚待业务确认。导入和查询都不自动选出唯一最终价格，不回退、不加价，不生成工单或案件金额。
