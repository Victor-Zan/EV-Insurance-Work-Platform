## 本地网站稳定性

原启动器通过 Start-Job 托管三个服务，一个服务退出或托管会话关闭时可能一起结束。新增 `scripts/Manage-Website.ps1`、`Run-WebsiteService.ps1`，各服务独立隐藏后台运行，启动完成后命令返回，退出启动终端不再联动关闭服务。按登记的路径、进程类型、启动时间检查归属后才停止进程树，不批量结束 Java/Node，不停止 Docker 或删除数据。

第二阶段目录的 `启动本地网站.ps1` 已接入新启动器，另有 `检查本地网站.ps1`、`停止本地网站.ps1`；同目录 `本地网站使用说明.md` 补全恢复步骤。运行记录及日志放在仓库外 `local-validation/website-background-*`，不保存凭据。启动器复用健康服务、补启动停止的服务；端口由未知进程占用时报告错误。没有配置开机自启或崩溃自动重启。
