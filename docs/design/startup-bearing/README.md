# 轴承启动加载界面

2026-11-23，基于用户选定的第二张轴承圆环方案实现，仅管理端首次打开／刷新生效。

## 行为

HTML 内置加载层与独立 45 秒超时保护，先展示再加载主程序。程序、路由挂载、字体、逐张图片解码、有限入场动画和绘制帧分别完成后推进；进度是准备步骤的加权完成度，不是下载字节比例。100% 后等待圆环追上数值，再用 280ms 淡出。正常缓存命中不人为延长等待。底层 app 在加载期保持 inert 和 aria-hidden。

轴承缓慢旋转，减少动态效果偏好关闭旋转、圆环过渡和淡出。错误或超时保留加载层并提供重新加载。已有登录会话沿用原路由，只等待其首屏 DOM、字体和图片，不覆盖业务页面各自的异步数据加载。
