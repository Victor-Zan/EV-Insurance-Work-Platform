# e保 · 海滨骑行展示原型

独立的 WebGL 滚动叙事页面，演示橙色两轮电动车、粉色长发、圆框眼镜的骑行女孩、城市海滨街道，以及服务站和维修网点。模型为代码生成的原创低多边形概念资产，不是指定品牌车型的精确复刻。

2026-11-09 按用户提供的海滨插画补充花店、窗台花箱、屋顶女儿墙、绿白/橙白条纹棚、垂藤、店前招牌、售货机、垃圾桶、小猫、饮品木箱、海堤礁石/救生圈/缆绳、灯塔与立体海鸥；人物随后按同一参考图重做为粉色长发、圆框眼镜、白色短袖、黄色碎花裤、白鞋及米色挎包的女孩，替换原头盔人物。独立的 rider.js 负责人物几何、服装纹理及发丝轻摆。`scenery-details.js` 管理景物模型，花叶与礁石使用实例化批量绘制。保留滚动场景，柔化光照并扩展桌面取景；当前入口与文案见下文。

## 本机运行

从本目录执行 `npm ci`，然后 `npm run dev`；访问 http://127.0.0.1:5198/ 。复用仓库 `admin-web/node_modules` 中的 Vite，因此先确保管理端依赖已安装。`npm run build` 输出本目录 `dist/`；`npm run preview` 可预览构建结果。

滚动或点击“了解服务 / 查看下一步”切换场景。页面面向车主，以“查看我的维修”为主入口；删除底部编号章节、暂停按钮、英文标语、冗余说明与技术入口弹窗，保留系统减少动态效果偏好。业务按钮直接链接原有本机 `http://127.0.0.1:5196/#/` 登录页，该服务需另行运行；只是入口文案调整，不改变既有角色权限、认证或业务接口。沿途四组摆件分别为首屏深灰白坐猫与饮品木箱、花篮、橘白睡猫与食碗、救生圈与缆绳。

## 微信小程序适配评估

可采用现有 uni-app 中的原生服务按钮叠加轻量 WebGL 场景，但本轮未迁移。微信官方 [threejs-miniprogram](https://github.com/wechat-miniprogram/threejs-miniprogram) 提供小程序 WebGL 适配，其 README 标明基于 Three.js 0.108.0；本原型为 0.170.0，不能直接替换依赖照搬。需处理渲染上下文、DOM 纹理创建、滚动/触摸及页面生命周期，并按设备能力减少阴影、几何量和像素比，离屏停止渲染，提供静态降级。最终以 iOS / Android 微信真机的兼容性、首屏耗时和流畅度验证为准。
