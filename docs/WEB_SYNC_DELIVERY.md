## 配置与数据边界

仓库只提交 `.env.example` 的空值/默认开关。真实 Key、安全码、JWT、数据库密码、私密 .env、运行脚本配置、现有网点/区域资料和业务库均不随 Git 同步。其他开发者需要在自己的后端安全配置中提供对应值：

- `MAP_PROVIDER=AMAP_WEB_V1` 和 `AMAP_WEB_SERVICE_KEY`：真实 Web 服务实现。
- `AMAP_JS_ENABLED=true`、`AMAP_JS_API_KEY`、`AMAP_JS_SECURITY_CODE`：真实底图；安全码仅服务端固定资源代理使用，不能放入 VITE 变量。
- `PUBLIC_WORKSHOP_ENABLED=true`：公开维修地点及本案临时门店；默认关闭。
- `AMAP_CALL_POLICY=PROVIDER`：仅由可信部署配置显式开启；不会购买或报告高德余额。CONTROLLED 模式仍需原持久授权，不因拉取代码自动发放。
- 前端 `VITE_API_BASE_URL` 指向匹配版本的后端；开发代理从其 origin 读取，JS 代理须保持同源访问。

行政区域及真实网点资料仍由各自数据库维护，Git 拉取代码不会复制本机数据库。不能把现有5210实例的运行状态或合成资料视为共享仓库默认数据。
