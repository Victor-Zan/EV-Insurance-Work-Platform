## 官方契约核对

- [地理/逆地理编码](https://lbs.amap.com/api/webservice/guide/api/georegeo)：结构化地址及城市 city/adcode；返回省、市、区县、adcode、匹配级别。city 不代替服务端行政归属校验。
- [驾车路径规划2.0](https://lbs.amap.com/api/webservice/guide/api/newroute)：/v5/direction/driving，origin/destination 为经度,纬度，最多六位小数；show_fields=cost 请求预计秒数；距离为米。策略32为高德推荐，并非理论最短距离。多个路线按返回方案编号保留，策略方案选择需明确记录。
- [批量距离](https://lbs.amap.com/api/webservice/guide/api/direction)：最多100个起点对单一终点，不支持把送店方向反转当作等价批量调用。
- [错误码](https://lbs.amap.com/api/webservice/guide/tools/info)：同时检查HTTP及status/infocode。供应商原始错误正文不返回客户端或进入日志。

真实调用默认关闭；自动测试只使用合成HTTP响应。没有真实调用预算及测试数据授权前，不以配置Key为由发起联调。不做跨查询供应商结果缓存、不保存完整响应或路线轨迹；只在当前交互流程内暂存位置确认与分页所需结果，不能复用为地理数据库或离线数据集。

[服务协议](https://lbs.amap.com/pages/terms/)（核对日期2026-10-15）4.12及7.3限制超授权存储、缓存和二次封装。当前不建立供应商地理数据库、不持久保存路线/完整返回；管理员维护的自有GCJ-02坐标须明确来源，不能默认将高德地理编码结果永久入库。商业使用及额外数据留存权限须由账号所有人核实，不据此购买或开通服务。

## 当前可运行接口与入口

客服工单详情→“派单与异常”→“车辆当前停放位置”。同时显示案件事故区域和车型，选择广东城市/区县、填写街道门牌/明确地标，点击“解析停放位置”。展示全部地址候选、行政归属、匹配级别；仅精确且相符的候选可明确确认。修改输入立即清除当前确认、推荐及其网点选择，不修改事故地址。可按网点所在城市明确收窄范围，点击“查询附近可服务网点”，全体合格候选计算后分页；失败项距离为空，不能称完成全体真实排序。选网点只填入原控件，点击原派单/改派按钮才提交。

管理员→组织→维修网点→“车型与位置”：按品牌筛选并维护车型适配；输入并确认自有GCJ-02经纬度、广东区县后追加定位版本。真实模式保存前逆编码校验行政归属；dev Mock只能显式保存SYNTHETIC_TEST，不能冒充真实位置。真实坐标不接受Mock核实，也不允许真实模式采用合成位置计算道路距离。原地址修改后旧位置失效。当前未接交互地图，不需要JS API Key；Web服务Key不会进入浏览器。

HTTP：连接3秒、读取8秒、总10秒、响应1MiB、禁止重定向与自动重试；本机每秒请求上限（默认2）及并发安全进程总预算（默认0关闭）。路线循环按550ms最小间隔；查询总执行窗口60秒，已开始的一次调用另受10秒总超时，管理端此操作等待上限75秒。凭据/权限/额度/限流/本机预算错误立即停止后续外呼，剩余项同样距离未知。只有受控错误码和中文说明出界，不附含Key/地址的异常cause/URL/正文。路线方向车辆→网点，v5 strategy=32，主方案alternative=0，米/秒；不按最快耗时重新挑方案。

## 数据与一致性

仅追加V17：shop_model_capability（复用price_model及repair_shop）、不可变shop_map_location版本、map_recommendation_query及map_recommendation_shop内部追溯元数据。既有迁移完全不变。坐标为管理员输入与自有地址快照，新增历史不覆盖；能力变化同事务审计。服务区域仍复用shop_service_region，精确匹配事故区县，不把网点地址作为服务范围。

查询元数据只持久保存内部ID、幂等摘要、方向/策略、状态、最多50次尝试数、时间和所用网点定位版本，不保存客户地址、位置坐标、道路距离、供应商响应或凭据。位置候选最多1000个/每客服40个，10分钟到期；分页结果最多1000个查询、2分钟到期，均进程内当前交互快照。分页和同键重放不再调用供应商，重启/快照丢失时返回进行中或过期，不自动重算；数据库幂等元数据防止旧键重放再次外呼。新查询必须用户明确操作、新键，进程总预算重启会归零，禁止以重启延长已批准联调额度。

外呼在数据库事务和业务行锁之外。推荐提交锁案件后锁网点，复核原事故区县服务区域、启用、精确车型及最新位置版本，再调用原派单应用服务；原人工接口保留既有规则。已有成功业务命令按原幂等记录重放，即使推荐后来过期也不会重复派单。推荐结果不代表已派单。
