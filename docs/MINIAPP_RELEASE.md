## 2. 候选构建、指纹与兼容

在`miniapp/`执行：

```powershell
npm ci
npm run typecheck
npm run build:mp-weixin
npm run release:inspect
```

已有依赖未改变时不必重复npm ci；没有源码变更不重复业务测试。本轮增加构建工具后两目标构建/typecheck通过，S03—S07已有证据保留在PROGRESS，不声称重新全测。

`build-receipt.json`由Vite构建自动生成，记录目标、版本、源代码/锁文件SHA-256、已验证格式的公开API base和源码AppID；无配置为null，非法地址不复制，AppSecret/JWT从不进入收据。指纹覆盖src（含素材）、package/lock、Vite配置及收据生成器。不是数字签名；手改收据、绕过构建或任意伪造产物不能被它证明可信。

`release:inspect`仅离线读取`dist/build/mp-weixin`，不外呼、配置服务、上传或发布。报告输出`.task-log/s08-candidate/inspection.json`，包含所有产物逐文件SHA-256、总指纹、字节数、源码漂移、域名检查设置、登录首屏、统计开关及已知合成/私钥标记检查。它不完整扫描全部秘密，也不能证明日志或真实服务合规。退出码2=本地条件被拦截；0=本地检查通过，**仍需全部外部证据，不是发布通过**。`publicationApproved`永远false。当前预期2：源码无正式AppID、测试生成AppID与源码不同、API未配置。

构建使用`VITE_API_BASE_URL=https://<批准域名>/api/v1`。兼容旧登录地址时必须准确结尾`/api/v1/auth/wechat/login`，生产优先只配置base。同一base承载请求、上传和鉴权下载，不让客户端直接访问MinIO或api.weixin.qq.com。禁止将根目录管理端使用的相对`/api/v1`误用为小程序地址；禁止把敏感服务端变量命名为VITE_。本地测试号保留操作仅适用于本机预览，正式构建必须核对源码/收据/生成配置/平台账号四者一致。

兼容基线：REST `/api/v1`，统一`code=SUCCESS/data`，身份协议v2；后端须包含当前V1—V40业务迁移及V41微信绑定、V42身份历史索引。V33/V34是原未发布本地微信扩展的旧编号，不适用于当前源码。具体依赖包括：CurrentUser重验；单一OWNER/REPAIR_SHOP和shopId；报价arrivalPhotoUploaded布尔；报价/维修/工单独立版本；报价OCR人工快照revision；完工照片冻结；网点过滤资金摘要。客户端不得忽略缺字段或回退DEMO。已有H5/管理端账号密码、邀请兼容路径继续保留。迁移只前进，不删除/改写已共享迁移。当前新隔离库含额外dev基础迁移，共43项；不等于现有业务库升级或旧隔离库编号转换已验证。

候选登记须包含：构建文件总指纹、源码指纹、Git HEAD及dirty事实、依赖锁指纹、后端JAR指纹/迁移清单、配置版本（不含秘密）、执行者和时间、实际AppID/主体核对证据、域名和证书验证、测试账号范围、平台包体报告。每次重建重新登记，旧证据不能自动覆盖新包。忽略目录证据含潜在敏感材料，不整目录发送或纳入公开仓库。
