# 客服案件链路滚动交互方案

日期：2026-10-16。状态：整体滚动方案待实施；用户后续要求的顶栏约2/3高度及结算按钮反馈作为D-059局部实施；右侧任务框取消内部滚动及精简显示作为D-060实施。

## 1. 已确认的要求

1. 顶部案件摘要与案件流程固定，完整显示。滚动不改变其内容、尺寸、透明度或布局。
2. 右侧任务框固定、完整显示，不随正文移动，没有内部滚动条。
3. 窗口较矮时仍保留右侧任务框，优先精简文字、压缩间距，不改成抽屉。
4. 本轮仅调整客服案件页的布局及滚动交互；流程顺序、角色权限、材料校验、报价及资金规则沿用现有实现。

## 2. 页面布局

```text
┌─────────────────────────────────────────────────────────────┐
│ 全局导航 / 搜索                                      固定   │
├─────────────────────────────────────────────────────────────┤
│ 案件摘要：案件号、车辆、联系方式、案件状态            固定   │
│ 建单 → 派单 → 报价 → 审核 → 核损 → 维修 → 收车 → 资金 → 完成 │
├──────────────────────────────────────┬──────────────────────┤
│ 当前任务 / 案件资料 / 记录            │ 当前任务             │
│                                      │ 办理方               │
│ 当前节点正文                         │ 材料状态             │
│                                      │ 缺项数量             │
│ 只有此区域纵向滚动                   │                      │
│                                      │ 固定、完整、无滚动条 │
├──────────────────────────────────────┤                      │
│ 当前节点操作区：继续 / 确认 / 等待    │                      │
└──────────────────────────────────────┴──────────────────────┘
```

正常浏览时仅中间正文出现一根纵向滚动条。页面最外层不再与正文同时滚动；右框不建立滚动容器。左侧系统导航保持现有导航行为。

## 3. 顶部案件摘要与流程

- 进入案件后按当前窗口宽度一次排布，滚动过程中保持相同位置与高度。顶栏按用户补充要求控制为原高度约三分之二，优先优化排布及留白，保留文字可读性。
- 案件摘要采用紧凑行布局，信息清晰完整；长内容可正常换行，不因下滑隐藏。
- 完整九节点流程始终显示。取消滚动触发的摘要淡出、缩小、收起和位移动画。
- 节点颜色、名称和完成时间只随真实业务状态更新，不随滚动位置变化。
- 窗口尺寸改变时可重新排布，但不将滚轮位置作为排布依据。

## 4. 右侧任务框

固定在正文右侧，与正文滚动区并列，避免受正文长度和底部边界挤压。

| 内容 | 呈现方式 |
| --- | --- |
| 当前任务 | 一个清晰标题 |
| 办理方 | “由你办理”“等待网点”等简短状态，保留绿/黄语义 |
| 材料状态 | 保留当前必需及已有材料清单，每种材料一行，绿勾/红叉配合文字 |
| 缺项 | 显示“还缺 N 项”；详细字段和原因放在正文校验区，点击“继续”仍完整提示 |
| 补充材料与历史 | 从既有“案件资料”“记录”查看，不在右框重复展开长内容 |

取消随滚动改变的“当前查看”阅读标记，以及右框的独立滚动、位移动画、动态高度切换。材料和办理状态仍可因上传、提交或刷新真实更新。

矮窗口优先缩减上下留白、标题间距和材料行间距，去掉重复说明；不通过隐藏必需材料、截断任务信息或缩小到难以阅读来强行塞入。验收重点为1280×720、1366×768及1280×640的桌面视口。

## 5. 正文与材料预览

| 区域 | 新滚动行为 |
| --- | --- |
| 建单、派单、维修、收车及资金表单 | 高度随内容展开，共用正文主滚动条 |
| 材料列表、金额历史、状态记录 | 在正文内自然展开；长列表沿用分页，不另设纵向滚动框 |
| 报价原件、核损单、正式报价 | 正文中适宽预览完整页面，取消固定高度框内的纵向滚动；多张图片或多页PDF继续切换查看 |
| 报价核对表 | 行随正文展开，不叠加表格纵向滚动；优先调整列宽，窄窗口确需横向查看时仅保留必要的横向滚动 |
| 派单地图 | 普通滚轮用于正文滚动，保留已有网点选择操作；本轮不新增地图交互功能 |

放大原件时打开独立预览层：背景正文锁定；放大内容确实超出视口时只滚动预览层。关闭后恢复原正文位置，不出现背景和弹窗同时滚动。该滚动只在主动打开预览时存在。

## 6. 操作栏与位置保持

- “继续”“确认”“等待另一端”等操作区固定在正文下方，只占正文列宽，不遮盖右侧任务框。
- 为操作区留出真实布局空间，最后一行表单、表格及提示均能完整露出。
- 不再根据滚动到底部的判断来切换固定定位和普通定位。
- 切换案件或真实进入下一节点时，正文回到新任务顶部。
- 同一节点刷新、保存或更新材料时保留当前位置；放大预览关闭后回到原阅读位置。
- 不引入滚动吸附、自动翻屏、视差、滚动缩放等效果。

## 7. 实施范围

1. 客服案件详情布局：划分固定头部、唯一正文滚动区、固定任务框及操作区。
2. 移除滚动触发的compact和阅读位置状态；保留正常窗口尺寸适配。
3. 调整报价对照、维修授权、资金核损预览及材料组件中的嵌套滚动。
4. 统一各节点操作区的位置，并验证切换节点和关闭预览后的滚动位置。

不修改数据库、后端接口、案件状态或已录入材料。其他工作台页面、网点端与车主端不在本轮改造范围。

## 8. 验收标准

- 正常案件页仅正文有一根纵向滚动条，外层页面和右框均无纵向滚动条。
- 连续下滑、回到顶部、反复到底部，案件摘要和九节点流程位置、尺寸、透明度不变。
- 右框材料清单、办理状态完整可见；不同正文长度及矮窗口下无裁切、重叠或内部滚动。
- 所有客服办理节点均适用，包括报价左右对照、核损、维修、收车和资金。
- 正文最后一项不被操作栏遮挡，操作栏与右框不重影、不抖动。
- 普通滚轮经过单据、表格及地图时，优先保持正文连续滚动。
- 图片/PDF放大后能完整阅读，背景锁定，关闭不丢失原位置。
- 节点顺序、禁止越步、绿/黄状态、缺项提示及权限保持原有业务规则。
